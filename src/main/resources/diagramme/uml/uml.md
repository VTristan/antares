
UML → modéliser un système logiciel.
BPMN → modéliser un processus métier.

### UML
UML (Unified Modeling Language) est un langage de modélisation qui contient plusieurs types de diagrammes.

Le diagramme de classes est donc un type de diagramme UML.
UML
```
├── Diagramme de classes : Structure du système
├── Diagramme de séquence : Interactions entre composants
├── Diagramme de composants : Architecture
├── Diagramme de déploiement
├── Diagramme de cas d'utilisation : use case ; 
├── Diagramme d'activité
├── Diagramme d'états
└── ...
```

### BPMN

```
BPMN (Business Process Model and Notation) / Processus métier
│
├── Événements
├── Tâches
├── Gateways
├── Pools / Lanes
├── Flux
└── ...
```
