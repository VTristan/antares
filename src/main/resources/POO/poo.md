| Notion | Niveau attendu pour un PO |
|---|---|
| **Objet** | Comprendre qu'il représente une instance avec des données et comportements |
| **Classe** | Comprendre qu'elle définit la structure d'objets |
| **Attribut** | Donnée portée par un objet |
| **Méthode** | Comportement/action disponible |
| **Encapsulation** | L'objet contrôle l'accès et la modification de son état |
| **Association** | Relation entre objets |
| **Composition** | Un objet est constitué d'autres objets |
| **Héritage** | Une classe spécialisée hérite d'une classe plus générale |
| **Interface** | Contrat définissant des comportements attendus |
| **Polymorphisme** | Plusieurs implémentations derrière un même contrat |
| **Abstraction** | Masquer les détails pour exposer l'essentiel |
