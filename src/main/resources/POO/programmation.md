| Notion | Ce qu'elle doit comprendre | Priorité |
|---|---|---:|
| **Variable** | Une valeur stockée et nommée | ★★★ |
| **Type** | `String`, nombre, booléen, date, objet… | ★★★ |
| **Condition** | `if / else` = décision selon une condition | ★★★ |
| **Opérateurs logiques** | `AND`, `OR`, `NOT` | ★★★ |
| **Fonction / méthode** | Bloc réutilisable qui reçoit éventuellement des paramètres et retourne un résultat | ★★★ |
| **Objet / classe** | Bases de la POO | ★★★ |
| **Liste / collection** | Ensemble de données : clients, commandes… | ★★★ |
| **Boucle** | Répéter une opération sur plusieurs éléments | ★★ |
| **Exception / erreur** | Gestion d'une situation anormale | ★★ |
| **`null`** | Absence de valeur | ★★ |
| **Enum** | Liste fermée de valeurs possibles | ★★ |
| **Constante** | Valeur qui ne doit pas changer | ★ |
| **Portée d'une variable** | Où une variable est accessible | ★ |
| **Récursivité** | Fonction qui s'appelle elle-même | ★ |
